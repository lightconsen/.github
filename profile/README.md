# LightConsen

**Local-first AI software.** We build applications that put an AI agent on the user's own
machine — their files, data and API keys stay on their own device.

LightConsen LLC · Wyoming, United States · [lightconsen.com](https://lightconsen.com)

## Products

**[Syscity](https://syscity.net)** — an AI agent system: a runtime that lets AI control the
desktop, browser, files and code, running natively on macOS, Windows, Linux, iOS and Android.
Apache-2.0 core.

**[Kiwano](https://kiwano.cc)** — a local-first AI provider manager: one local gateway for every
coding agent, with failover, quotas and per-agent cost tracking. Apache-2.0.

**[Kiwano Hub](https://models.kiwano.cc)** — open model and price data for 58 LLM providers,
checked against each vendor's own published pages and dated on every row.
